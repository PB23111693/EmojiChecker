# 用户手册

项目：表情符号课堂情绪检查器系统
版本：2.0
适用对象：学生、教师、管理员、AI 进程操作者

## 1 系统入口

| 入口 | 地址 | 说明 |
| --- | --- | --- |
| Web 系统 | `http://127.0.0.1:8000` | 三角色共用，登录后按角色进入 |
| 桌面客户端 | `python desktop-client/client.py` | 学生端，C/S 通道 |
| AI 进程 | `python ai-worker/run.py` | 命令行运行，无 Web 界面 |
| 接口文档 | `http://127.0.0.1:8000/docs` | 开发与调试使用 |

首次使用请确认管理员已执行初始化脚本，并已创建课堂与名单。

## 2 账号与登录

### 2.1 演示账号

| 角色 | 账号 | 密码 |
| --- | --- | --- |
| 管理员 | admin | Admin@2026 |
| 教师 | teacher_zhang / teacher_li | Emoji@2026 |
| 学生 | stu2021001 至 stu2021008 | Emoji@2026 |

演示账号仅用于本地初始化，正式使用必须修改密码。

### 2.2 学生注册

1. 打开登录页，点击“注册”。
2. 填写用户名、密码、确认密码与可选邮箱。
3. 用户名以字母开头，3 至 32 位，可含字母、数字与下划线。
4. 密码 8 至 64 位，至少包含字母与数字。
5. 注册成功后返回登录页。

学生注册不需要邀请码，也不能选择角色。注册后需由管理员把你加入课堂名单，才能提交反馈。

### 2.3 教师注册

1. 在注册页切换到“教师注册”。
2. 填写账号信息与教师邀请码。
3. 邀请码由部署方配置；未配置时页面提示入口未开放。
4. 注册成功后使用新账号登录。

### 2.4 管理员注册

1. 在注册页切换到“管理员注册”。
2. 填写账号信息与管理员邀请码。
3. 管理员邀请码与教师邀请码相互独立；未配置时入口关闭。
4. 注册行为写入审计日志。

### 2.5 修改密码

登录后点击右上角用户名 → 个人设置 → 输入原密码与新密码 → 提交。修改成功后旧令牌立即失效，需要使用新密码重新登录。

### 2.6 忘记密码

系统不提供自助找回。请联系管理员重置账号或重新创建。

## 3 学生使用 Web 端

### 3.1 查看我的课堂

登录后进入“我的课堂”。页面按进行中、未开始、已结束排序，显示课程、教师、班级、教室、时间、状态与本课反馈条数。

- 只有“进行中”的课堂显示可用的“提交反馈”按钮。
- 未开始与已结束课堂只能查看记录。
- 若列表为空，说明管理员尚未把你加入任何课堂名单。

### 3.2 提交反馈

1. 在进行中的课堂卡片点击“提交反馈”。
2. 页面显示课程、教师、班级、教室与时间。
3. 从七类表情中选择最接近此刻感受的一项：开心、平静、低落、生气、惊讶、害怕、厌恶。
4. 点击“确认提交”。
5. 成功后显示“反馈已记录”与服务器时间；可继续查看我的记录或再记一次。

规则：

- 同一课堂每 30 秒只能提交一次；页面会提示剩余限制。
- 提交后不能修改。
- 网络失败时不要连续点击，等待提示后重试；系统使用事件编号保证重试不产生重复记录。
- 课堂开始前、结束后或取消后提交都会被拒绝。

### 3.3 查看我的记录

进入“我的记录”：

- 仅显示本人的手动记录，不包含 AI 观察。
- 可按课堂与日期筛选，分页浏览。
- 字段包括时间、课程、班级、表情与来源。
- 从“我的课堂”点击“查看记录”会自动带上该课堂筛选。

## 4 学生使用桌面客户端

### 4.1 启动与登录

```powershell
cd desktop-client
..\.venv\Scripts\python.exe client.py
```

默认连接 `http://127.0.0.1:8000`；其他地址使用 `--base-url`。输入用户名与密码后登录。令牌只保存在内存，关闭程序即失效。

### 4.2 我的课堂

- 顶部“刷新”重新加载课堂列表。
- 表格显示课程、班级、教室、开始、结束与状态。
- 双击进行中的课堂或选中后点击“进入反馈”。

### 4.3 提交反馈

1. 在“我的课堂”选择进行中的课堂。
2. 切换到“提交反馈”页签。
3. 点击七类表情按钮之一。
4. 下方显示提交成功时间或失败原因。

同一时间片限制与 Web 端一致。桌面客户端只面向学生提交；教师与管理员账号可以登录查看课堂，但不能提交。

### 4.4 我的记录

“我的记录”页签显示本人手动记录，支持上一页、下一页与刷新。

### 4.5 修改密码

“修改密码”页签输入原密码、新密码与确认密码。成功后程序返回登录页，需要使用新密码重新登录。

## 5 教师使用

### 5.1 课堂看板

登录后进入“课堂看板”：

1. 选择课程，再选择课堂。默认选中进行中的课堂。
2. 顶部显示课程、班级、教室、时间、状态与更新时间。
3. 左侧“手动反馈”显示反馈次数、参与学生、名单覆盖率与类别分布。
4. 右侧“AI 观察”显示有效观察次数、置信度阈值、最近有效样本时间与类别分布。
5. 底部“分钟趋势”可切换手动或 AI。
6. “参与学生”表列出有手动记录的学生与次数，点击“查看记录”查看该生在本课堂的明细。

### 5.2 指标理解

| 指标 | 含义 | 注意事项 |
| --- | --- | --- |
| 反馈次数 | 手动记录条数 | 同一学生可在不同时间片多次提交 |
| 参与学生 | 有手动记录的学生去重数 | 不等于到课人数 |
| 名单覆盖率 | 参与学生 / 名单人数 | 名单为空时显示不适用 |
| AI 有效观察 | 通过阈值的人脸结果数 | 同一人跨帧重复计数，不是独立学生数 |
| 最近有效样本 | 最近一条 AI 记录的观测时间 | 长时间无样本不代表设备一定离线 |

手动与 AI 分区展示，不合并为单一“班级情绪得分”。教师只能查看本人所授课程；访问其他课程会显示课堂不存在。

### 5.3 多维统计

教师菜单包含“多维统计”。选择课程、班级、日期范围与来源后查询，可查看所授课程的表情分布与分钟趋势。结果自动限定本人所授课程；页面不显示 CSV 导出按钮，导出仅管理员可执行。

### 5.4 刷新机制

- 页面每 3 秒自动刷新。
- 有新记录时 WebSocket 触发一次立即刷新。
- 网络失败显示“更新失败”，保留上次数据并显示上次成功时间。
- 离开页面停止轮询与连接。

## 6 管理员使用

### 6.1 用户管理

进入“用户管理”：

- 按角色、状态、关键字筛选。
- “新建用户”可创建教师或学生；管理员账号通过管理员注册入口或初始化脚本创建。
- 启停账号：停用后该用户立即无法登录，已登录令牌失效。
- 不能停用当前登录账号，也不能停用最后一个启用状态的管理员。
- 页面不显示密码哈希。

### 6.2 课程与课堂

进入“课程与课堂”：

1. 左侧选择课程，或点击“新建课程”并指定教师。
2. 右侧“新建课堂”填写班级、教室、起止时间与 AI 阈值。
3. 课堂列表显示状态、名单人数、阈值与操作。
4. “名单”打开学生选择抽屉，搜索并勾选学生，保存后立即生效。
5. “编辑”可修改未开始课堂的班级、教室、时间与阈值。
6. “取消”将课堂标记为已取消；取消后学生不能提交。未开始课堂可恢复。

规则：

- 课堂开始后时间、名单与阈值冻结，操作按钮禁用。
- 名单表示提交资格，不代表出勤。
- 同一课堂重复保存名单不会产生重复成员。
- 非学生、停用学生不能加入名单。
- 班级名会自动统一全角半角与多余空白。

### 6.3 记录明细

进入“记录明细”：

1. 按课程、班级、日期范围、来源与表情筛选，点击“查询”。
2. 表格显示观测时间、课程、班级、学生、表情、来源、置信度、设备与事件编号。
3. 手动记录的学生列显示账号；AI 记录固定显示“匿名”，置信度为模型得分。
4. 使用底部分页浏览全部记录，点击“刷新”重新加载。

该页面用于核对统计与导出结果；管理员可在此确认某条记录是否真实入库。

### 6.4 多维统计与导出

进入“多维统计”：

1. 选择课程、班级、日期范围与来源，点击“查询”。
2. 指标卡显示记录总数、手动反馈、AI 观察与参与学生。
3. 左侧为表情分布柱状图，右侧为分钟趋势折线图。
4. 点击“导出 CSV”下载当前筛选条件下的记录。
5. “重置”清空筛选并重新查询。

导出说明：

- 文件为 UTF-8 BOM，Excel 可直接打开中文。
- 文本字段若以 `= + - @` 等开头会前置单引号，防止公式执行。
- 单次最多 50000 行；导出行为写入审计日志。

### 6.5 审计日志

进入“审计日志”，按操作类型筛选，查看注册、登录失败、创建用户、停用账号、建课、改课堂、保存名单与导出记录。日志不含密码与密钥。

## 7 AI 进程操作

### 7.1 准备

1. 确认后端已启动，课堂处于进行中。
2. 确认 `.env` 的 `AI_SERVICE_KEY`、`AI_DEVICE_ID` 与 `ai-worker/config.yaml` 一致。
3. 已执行 `python scripts/download_models.py`。

### 7.2 启动

```powershell
cd ai-worker
$env:AI_SERVICE_KEY="dev-ai-service-key-change-me"
$env:AI_DEVICE_ID="demo-device-01"
..\.venv\Scripts\python.exe run.py --config config.yaml
```

窗口显示摄像头画面，人脸上叠加类别与置信度。底部显示课堂、阈值与输入类型；回放输入会显示红色“REPLAY INPUT”。

### 7.3 观察结果

- 教师看板“AI 观察”区应在数秒内出现新记录。
- 低于阈值的人脸不显示绿色框，也不入库。
- 日志显示采样帧数、人脸数、低分数量、上传接收与拒绝数量。
- 按 `q` 或 Ctrl+C 退出；课堂结束后进程自动停止。

### 7.4 隐私要求

- 不拍摄与上传可识别个人的画面；原始帧只在内存中使用。
- 回放输入必须标注，不得在演示中冒充现场采集。
- 演示前征得在场人员同意；不把摄像头画面上传到公网。

## 8 常见提示与处理

| 提示 | 含义 | 处理 |
| --- | --- | --- |
| 你不在该课堂的参与名单中 | 学生未被安排 | 联系管理员加入名单 |
| 课堂尚未开始 / 已结束 | 不在提交时间窗 | 等待开始或查看历史 |
| 同一课堂每 30 秒只能提交一次 | 时间片限制 | 等待提示时间后重试 |
| 事件编号已被占用且内容不一致 | `event_id` 冲突 | 刷新页面后重新提交 |
| 登录已失效，请重新登录 | 令牌过期或改密 | 重新登录 |
| 账号已停用 | 管理员停用 | 联系管理员 |
| 课堂不存在 | 无权访问或对象不存在 | 确认课程与课堂选择 |
| 导出 0 行 | 当前筛选无记录 | 调整筛选条件 |
| AI 服务密钥无效 | 密钥不一致 | 统一后端与 AI 配置 |
| 设备标识与服务密钥不匹配 | `device_id` 不一致 | 统一配置 |
| 最近 15 秒无有效样本 | 无人脸或全低于阈值 | 调整光线与位置，不代表设备离线 |

## 9 界面约定

- 七类表情同时显示图标与中文，不只依赖颜色。
- 危险操作（取消课堂、停用账号）二次确认。
- 空数据统一显示“暂无数据”，不填充中性情绪。
- 网页显示、课堂时间编辑及演示刷新输出统一使用北京时间（Asia/Shanghai，UTC+8），不受浏览器默认时区影响；服务器仍存储 UTC，接口时间带时区。
- 错误提示来自服务端 `message` 字段，参数错误会列出前三条具体原因。
