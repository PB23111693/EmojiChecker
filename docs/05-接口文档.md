# 接口文档

项目：表情符号课堂情绪检查器系统
版本：2.0
编制日期：2026 年 10 月 29 日
在线文档：启动后端后访问 `/docs`；机器可读描述见 `docs/openapi.json`

## 1 通用约定

### 1.1 基础信息

| 项目 | 约定 |
| --- | --- |
| 基础地址 | `http://127.0.0.1:8000` |
| 前缀 | `/api/v1`（健康检查 `/health` 除外） |
| 编码 | UTF-8 |
| 请求体 | `application/json` |
| 时间 | ISO 8601，带时区偏移或 `Z`；库内 UTC |
| 分页 | `page` 从 1 开始，`page_size` 默认 20，最大 100 |

### 1.2 响应结构

成功：

```json
{
  "code": 0,
  "message": "ok",
  "data": {},
  "request_id": "b8560382d1804b24b289dc086445713d"
}
```

失败：

```json
{
  "code": 40900,
  "message": "同一课堂每 30 秒只能提交一次，请稍后再试",
  "data": null,
  "request_id": "076242b3f0f34f2fb67ff7df36ed5c69",
  "errors": null
}
```

`request_id` 同时写入响应头 `X-Request-Id`，日志按该字段串联。分页 `data` 结构为 `{items, page, page_size, total}`。

### 1.3 认证方式

| 调用方 | 请求头 | 说明 |
| --- | --- | --- |
| 用户 | `Authorization: Bearer <token>` | 登录获得，有效期 60 分钟 |
| AI 进程 | `X-AI-Service-Key: <key>` | 与环境变量 `AI_SERVICE_KEY` 一致，不能使用用户令牌 |

改密、停用、启用会递增 `auth_version`，旧令牌立即返回 401。

### 1.4 HTTP 状态与业务码

| HTTP | 业务码 | 含义 |
| --- | --- | --- |
| 200 | 0 | 成功 |
| 201 | 0 | 创建成功 |
| 401 | 40100 / 40101 | 未登录、令牌失效或用户名密码错误 |
| 403 | 40300 | 角色或数据权限不足 |
| 404 | 40400 | 对象不存在或不在可见范围 |
| 409 | 40900 | 状态冲突、重复时间片、事件编号冲突 |
| 422 | 42200 | 参数校验失败 |
| 429 | 42900 | 请求过于频繁 |
| 500 | 50000 | 服务内部错误 |
| 503 | 50300 | 服务暂不可用 |

## 2 认证接口

### 2.1 POST /api/v1/auth/register

公开。学生注册不需要 `role`；教师与管理员必须提供对应邀请码。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| username | string | 是 | 字母开头，3 至 32 位 |
| password | string | 是 | 8 至 64 位，至少字母与数字 |
| email | string | 否 | 格式校验，不用于找回密码 |
| role | string | 否 | `TEACHER` 或 `ADMIN`；省略为学生 |
| invite_code | string | 条件 | `role` 为教师或管理员时必填 |

学生注册：

```http
POST /api/v1/auth/register
Content-Type: application/json

{"username": "stu2021009", "password": "Abc12345", "email": "stu@example.com"}
```

管理员注册：

```json
{
  "username": "admin_new",
  "password": "Abc12345",
  "role": "ADMIN",
  "invite_code": "ADMIN2026"
}
```

返回 201：

```json
{
  "code": 0,
  "message": "注册成功",
  "data": {"id": 12, "username": "admin_new", "role": "ADMIN", "status": "ACTIVE"},
  "request_id": "..."
}
```

失败：用户名重复 409；邀请码错误或未配置 422；弱密码 422；角色非法 422。

### 2.2 POST /api/v1/auth/login

```json
{"username": "stu2021001", "password": "Emoji@2026"}
```

返回：

```json
{
  "code": 0,
  "message": "登录成功",
  "data": {
    "access_token": "eyJ...",
    "token_type": "bearer",
    "expires_at": "2026-10-29T14:30:00Z",
    "user": {"id": 4, "username": "stu2021001", "role": "STUDENT"}
  },
  "request_id": "..."
}
```

密码错误返回 401 / 40101，账号停用返回 403 / 40300。

### 2.3 PUT /api/v1/auth/password

需要用户令牌。

```json
{"old_password": "Emoji@2026", "new_password": "Xyz98765"}
```

成功返回提示信息；原密码错误 401；新密码过弱或与原密码相同 422。成功后旧令牌立即失效。

## 3 用户接口

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/v1/users/me` | 登录 | 当前用户 |
| GET | `/api/v1/admin/users` | 管理员 | 分页查询，支持 `role`、`status`、`keyword` |
| POST | `/api/v1/admin/users` | 管理员 | 创建教师或学生，不能创建管理员 |
| PATCH | `/api/v1/admin/users/{id}/status` | 管理员 | `{"status":"ACTIVE"}` 或 `DISABLED` |
| GET | `/api/v1/admin/teachers` | 管理员 | 教师下拉列表 |
| GET | `/api/v1/admin/audit-logs` | 管理员 | 审计日志，支持 `action` 筛选 |

停用最后一个启用管理员或停用当前账号返回 409。

## 4 课程、课堂与名单

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/v1/courses` | 登录 | 按角色返回可见课程 |
| POST | `/api/v1/admin/courses` | 管理员 | 创建课程并指定教师 |
| GET | `/api/v1/sessions` | 登录 | 课堂列表，支持 `course_id`、`class_name`、`status`、分页 |
| GET | `/api/v1/sessions/{id}` | 登录 | 课堂详情 |
| POST | `/api/v1/admin/sessions` | 管理员 | 创建课堂 |
| PATCH | `/api/v1/admin/sessions/{id}` | 管理员 | 未开始时修改或取消 |
| GET | `/api/v1/admin/sessions/{id}/members` | 教师/管理员（按归属） | 查询名单；学生不能读取全班名单 |
| PUT | `/api/v1/admin/sessions/{id}/members` | 管理员 | 整体保存名单 |
| GET | `/api/v1/admin/classes` | 教师/管理员 | 班级候选与课堂数 |
| GET | `/api/v1/sessions/{id}/students` | 教师/管理员 | 本课堂有手动记录的学生与次数 |

创建课堂请求：

```json
{
  "course_id": 1,
  "class_name": "计科2101",
  "room": "实验楼A301",
  "start_at": "2026-10-30T08:00:00+08:00",
  "end_at": "2026-10-30T09:40:00+08:00",
  "ai_threshold": 0.6
}
```

约束：结束时间晚于开始时间；时间必须带时区；`ai_threshold` 在 0 至 1；班级名做 NFKC 与空白归一。课堂开始后 PATCH 返回 409。

保存名单：

```json
{"user_ids": [4, 5, 6]}
```

返回 `member_count` 与成员列表；重复 ID 自动去重；非学生或停用账号返回 422；开始后返回 409。

## 5 表情记录

### 5.1 POST /api/v1/emoji

学生令牌。

```json
{"event_id": "a3f1c2d4e5b6470891a2b3c4d5e6f708", "session_id": 6, "emotion": "HAPPY"}
```

- `event_id` 长度 8 至 36，建议 32 位 UUID 十六进制。
- `session_id` 必须为本人名单内的进行中课堂。
- 不接受 `user_id`、`source`、`observed_at`，传入也不会生效。

成功：

```json
{
  "code": 0,
  "message": "提交成功",
  "data": {"record_id": 275, "observed_at": "2026-10-29T12:32:03.223539Z", "duplicate": false},
  "request_id": "..."
}
```

同 `event_id` 重试：

```json
{"code": 0, "message": "该次提交已处理", "data": {"record_id": 275, "duplicate": true}}
```

异常：不在名单 403；课堂未开始/已结束/已取消 409；时间片内重复 409；事件编号内容冲突 409。

### 5.2 GET /api/v1/emoji/history

登录。学生固定为本人手动记录；教师固定为所授课程；管理员可查全部。

| 参数 | 说明 |
| --- | --- |
| page / page_size | 分页 |
| course_id / session_id / class_name | 范围筛选 |
| from / to | 观测时间，左闭右开，支持带时区 |
| source | MANUAL / AI |
| user_id | 教师按学生查询时必须同时指定 `session_id` |
| emotion | 七类之一 |

返回分页记录，字段包括 `event_id`、课程、班级、学生、表情、来源、置信度、设备、观测与接收时间。

## 6 看板、统计与导出

### 6.1 GET /api/v1/dashboard/realtime

教师或管理员，参数 `session_id`。

```json
{
  "session_id": 6,
  "course_name": "软件工程实践",
  "class_name": "计科2101",
  "status": "ONGOING",
  "manual": {
    "total": 1,
    "participants": 1,
    "member_count": 8,
    "coverage": 0.125,
    "distribution": [{"emotion": "HAPPY", "count": 1, "ratio": 1.0}]
  },
  "ai": {
    "total": 1,
    "threshold": 0.6,
    "last_observed_at": "2026-10-29T13:40:19.827007Z",
    "distribution": [{"emotion": "NEUTRAL", "count": 1, "ratio": 1.0}]
  },
  "trend": [{"bucket": "21:40", "manual": 1, "ai": 1}],
  "last_update_at": "2026-10-29T13:40:30Z"
}
```

教师访问他人课堂返回 404。

### 6.2 GET /api/v1/statistics

教师或管理员。参数：`course_id`、`session_id`、`class_name`、`from`、`to`、`source`、`emotion`。

返回 `total`、`manual_total`、`ai_total`、`participants`、`distribution`、`by_source`、`trend` 与回显的筛选条件。教师结果自动限定所授课程。`participants` 只统计手动记录去重人数；按 `user_id` 筛选时只统计该学生；`source=AI` 时返回 0。

### 6.3 GET /api/v1/admin/emoji/export

管理员。参数与统计相同。返回 `text/csv` 文件流，不套 JSON。

响应头：

```text
Content-Type: text/csv; charset=utf-8
Content-Disposition: attachment; filename="emoji_records_20261029_214000.csv"
X-Export-Rows: 2
```

文件以 UTF-8 BOM 开头；危险文本前置单引号；单次最多 50000 行；导出写入审计日志。

## 7 AI 接口

### 7.1 GET /api/v1/ai/context

请求头 `X-AI-Service-Key`。参数 `session_id`、`device_id`。

```json
{
  "session_id": 1,
  "course_name": "软件工程实践",
  "class_name": "计科2101",
  "start_at": "2026-10-29T13:21:00Z",
  "end_at": "2026-10-29T14:21:00Z",
  "status": "ONGOING",
  "ai_threshold": 0.6,
  "sample_interval_seconds": 3,
  "max_faces_per_frame": 5,
  "emotions": ["HAPPY", "NEUTRAL", "SAD", "ANGRY", "SURPRISED", "FEARFUL", "DISGUST"]
}
```

设备与 `AI_DEVICE_ID` 不一致返回 403。

### 7.2 POST /api/v1/ai/emoji-results

```json
{
  "device_id": "demo-device-01",
  "session_id": 6,
  "model_version": "opencv-zoo-fer-2022july",
  "results": [
    {
      "event_id": "f782d88b0fda403296349326b6ccfb5f",
      "observed_at": "2026-10-29T13:40:19Z",
      "emotion": "NEUTRAL",
      "confidence": 0.7366
    }
  ]
}
```

返回 200 与逐事件结果：

```json
{
  "accepted": 1,
  "duplicates": 0,
  "rejected": 1,
  "details": [
    {"event_id": "...", "status": "ACCEPTED", "reason": null, "record_id": 277},
    {"event_id": "...", "status": "REJECTED", "reason": "BELOW_THRESHOLD", "record_id": null}
  ]
}
```

拒绝原因：`SESSION_NOT_ONGOING`、`OUT_OF_SESSION_WINDOW`、`OBSERVED_TOO_OLD`、`OBSERVED_IN_FUTURE`、`BELOW_THRESHOLD`、`EVENT_ID_CONFLICT`。

整批字段非法（缺字段、类型错误、非法枚举、置信度越界、批量超过 100）返回 422 且零写入。已成功事件的重复上报返回 `DUPLICATE` 与原记录 ID。

## 8 WebSocket

```text
ws://127.0.0.1:8000/ws/dashboard?session_id=6&token=<JWT>
```

连接成功后收到：

```json
{"type": "connected", "session_id": 6}
```

有新记录时收到：

```json
{"type": "emoji.created", "session_id": 6, "source": "MANUAL", "record_id": 275}
```

消息只作触发信号，客户端收到后调用 REST 拉取看板。认证失败以 4401 关闭。教师只能订阅所授课堂，学生只能订阅本人名单内课堂。

## 10 错误示例

参数校验失败（422）：

```json
{
  "code": 42200,
  "message": "请求参数不合法",
  "data": null,
  "request_id": "...",
  "errors": [
    {"loc": ["body", "emotion"], "msg": "Input should be 'HAPPY', 'NEUTRAL', ...", "type": "enum"}
  ]
}
```

越权（403）：

```json
{"code": 40300, "message": "没有权限执行该操作", "data": null, "request_id": "..."}
```

对象不在可见范围（404）：

```json
{"code": 40400, "message": "课堂不存在", "data": null, "request_id": "..."}
```
