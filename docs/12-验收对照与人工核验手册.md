# 大作业验收对照与人工核验手册

项目：表情符号课堂情绪检查器系统
版本：2.0
编制日期：2026 年 10 月 31 日
用途：对照《表情符号课堂情绪检查器系统》实验指导书检查交付完整性；对无法由自动化测试替代的项目，给出可重复的人工核验步骤。

## 1 使用说明

本手册分两部分：

1. **验收对照表**：指导书要求、实现位置、当前验证状态。
2. **人工核验用例 M01 至 M20**：每项包含前置条件、操作步骤、预期结果与记录方式。

状态含义：

| 状态 | 含义 |
| --- | --- |
| 自动验证 | 已有 pytest、接口联调或生产构建证据 |
| 需人工 | 依赖真实浏览器、摄像头、干净机器或课程平台，必须由团队执行 |
| 可选 | 指导书未强制或文档已标注为可选形态 |

人工核验时不要修改业务代码；发现问题记录在本文第 6 节，修复后重新执行对应用例。

## 4 核验前准备

在干净目录执行：

```powershell
git clone https://github.com/PB23111693/EmojiChecker.git
cd EmojiChecker
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
.\.venv\Scripts\python.exe -m pip install -r ai-worker\requirements.txt
Copy-Item .env.example .env
# 编辑 .env：填写 SECRET_KEY、AI_SERVICE_KEY，按需填写邀请码
cd backend
..\.venv\Scripts\python.exe scripts\seed_demo.py --reset
cd ..\frontend
npm install
npm run build
cd ..\backend
$env:PYTHONUTF8=1
..\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

打开 `http://127.0.0.1:8000/health` 与 `/docs`，均正常后开始人工用例。

## 8 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 页面 404 或空白 | 前端未构建 | `cd frontend && npm run build` 后重启后端 |
| 登录后立即失效 | `.env` 的 `SECRET_KEY` 为空且进程重启 | 配置固定密钥 |
| 看板只轮询无推送 | 缺少 `websockets` | `pip install websockets==17.3` |
| AI 报模型不存在 | 未下载模型 | `python scripts/download_models.py` |
| AI 设备不匹配 | `.env` 与 `config.yaml` 不一致 | 统一 `AI_SERVICE_KEY`、`AI_DEVICE_ID` |
| 学生不能提交 | 不在名单、课堂未开始或时间片内重复 | 管理员确认名单与时间 |
| 演示课堂全部过期 | 初始化时间过旧 | `seed_demo.py --refresh` |
| 导出中文乱码 | 非 Excel 打开 | 文件为 UTF-8 BOM，用 Excel 打开 |
| Git 推送超时 | 网络或代理 | 设置代理或改用 SSH；见 README 提交说明 |
