## 7 提交记录要求

指导书要求使用 Git 分支管理、提交记录真实可追溯。最终提交前应满足：

1. 仓库已初始化并推送到课程允许的远程地址，或随包提供完整 `.git` 目录。
2. 每名成员有可识别的提交记录，提交信息说明改动内容。
3. 主要功能通过功能分支与 Pull Request 合并，保留审查记录。
4. 最终版本打标签，如 `v1.0.0`。
5. 若使用本地仓库，保留 `git log --graph --oneline` 截图作为附件。

当前仓库尚未初始化 Git，此项需团队在提交前完成，不能以文档代替。
