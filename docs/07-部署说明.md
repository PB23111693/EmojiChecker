版本：2.0
编制日期：2026 年 10 月 29 日

## 1 部署形态

| 形态 | 用途 | 状态 |

| 本机直接运行 | 开发、答辩演示 | 已验证 |

## 2 环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10/11 或 Linux |
| Python | 3.12（3.10 以上可用，依赖版本以 `requirements.txt` 为准） |
| Node.js | 20 以上，仅构建前端时需要 |
| 内存 | 2 GB 以上；AI 推理建议 4 GB |
| 磁盘 | 1 GB 以上，模型约 5 MB |
| 摄像头 | 可选；无摄像头可用回放视频 |
| 端口 | 默认 8000，可修改 |

## 3 本机部署（Windows）

### 3.1 获取代码

将仓库复制到本地，路径可以包含中文；AI 进程对模型路径做了临时目录兼容处理。

### 3.2 创建虚拟环境

```powershell
cd 软件工程实践\SE-EmojiChecker
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
```

若网络受限，可使用系统已安装的包：

```powershell
python -m venv --system-site-packages .venv
.\.venv\Scripts\python.exe -m pip install argon2-cffi PyJWT opencv-python onnxruntime PyYAML requests
```

### 3.3 配置环境变量

```powershell
Copy-Item .env.example .env
```

编辑 `.env`：

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `SECRET_KEY` | 生产必填 | 随机长字符串；留空时进程生成临时密钥，重启后令牌全部失效 |
| `DATABASE_URL` | 否 | 默认 `sqlite:///./data/se_emoji.db` |
| `AUTO_CREATE_TABLES` | 否 | 默认 true，启动时自动建表 |
| `MANUAL_SLOT_SECONDS` | 否 | 默认 30，0 表示不限制；演示可设 0 |
| `TEACHER_INVITE_CODE` | 否 | 教师注册邀请码，留空关闭 |
| `ADMIN_INVITE_CODE` | 否 | 管理员注册邀请码，留空关闭 |
| `AI_SERVICE_KEY` | AI 必填 | AI 进程服务密钥，必须与 AI 配置一致 |
| `AI_DEVICE_ID` | AI 必填 | 设备标识，必须与 AI 配置一致 |
| `AI_ALLOWED_SESSION_IDS` | 否 | 逗号分隔的课堂白名单，留空不限制 |
| `CORS_ORIGINS` | 开发需要 | Vite 开发服务器地址，逗号分隔 |

密钥生成示例：

```powershell
.\.venv\Scripts\python.exe -c "import secrets; print(secrets.token_urlsafe(48))"
```

### 3.4 初始化演示数据

```powershell
cd backend
..\.venv\Scripts\python.exe scripts\seed_demo.py --reset
```

脚本创建 1 个管理员、2 个教师、8 个学生、2 门课程、4 节课堂与约 270 条记录。演示账号见 README。

录制或演示前若课堂已过期：

```powershell
..\.venv\Scripts\python.exe scripts\seed_demo.py --refresh
```

该命令只平移演示课堂时间，不删除用户与历史记录。

### 3.5 构建前端

首次部署或前端代码变更后：

```powershell
cd ..\frontend
npm install
npm run build
```

构建产物输出到 `frontend/dist`，后端启动时自动托管。若 `dist` 不存在，根路径返回后端占位信息，接口与 `/docs` 仍可用。

### 3.6 启动后端

```powershell
cd ..\backend
$env:PYTHONUTF8=1
..\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

`PYTHONUTF8=1` 用于避免 Windows 控制台中文日志乱码。局域网访问改为：

```powershell
..\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

并在 Windows 防火墙放行 8000 端口。

## 5 AI 推理进程

### 5.1 安装依赖与模型

```powershell
cd ai-worker
..\.venv\Scripts\python.exe -m pip install -r requirements.txt
..\.venv\Scripts\python.exe scripts\download_models.py
```

模型下载后校验 SHA256；失败时检查网络或手动放入 `models/`，校验值见 `ai-worker/models/README.md`。

### 5.2 配置

```powershell
Copy-Item config.example.yaml config.yaml
```

编辑 `config.yaml`：

| 字段 | 说明 |
| --- | --- |
| `api_base` | 后端地址，如 `http://127.0.0.1:8000` |
| `service_key` | 与 `.env` 的 `AI_SERVICE_KEY` 一致；也可用环境变量 |
| `device_id` | 与 `AI_DEVICE_ID` 一致 |
| `session_id` | 当前课堂 ID |
| `camera_index` | 摄像头序号，默认 0 |
| `video_path` | 回放文件路径；非空时优先 |
| `sample_interval` | 采样间隔，默认 3 秒 |
| `threshold` | 留空使用课堂阈值 |

### 5.3 启动

```powershell
$env:AI_SERVICE_KEY="dev-ai-service-key-change-me"
$env:AI_DEVICE_ID="demo-device-01"
..\.venv\Scripts\python.exe run.py --config config.yaml
```

参数：

```text
--session-id 1        覆盖课堂
--camera 0            摄像头序号
--video path          回放输入
--once                只采样一帧
--no-display          无窗口
--no-wait             课堂未开始立即退出
--threshold 0.6       覆盖阈值
--interval 3          覆盖采样间隔
```

退出码：0 正常；2 配置错误；3 认证失败；4 后端错误；5 启动失败。按 `q` 或 Ctrl+C 退出。

## 7 MySQL 8 部署（可选，未回归）

1. 创建数据库：

```sql
CREATE DATABASE se_emoji CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
```

2. 执行 `db/schema_mysql.sql`。
3. 修改 `.env`：

```text
DATABASE_URL=mysql+pymysql://se_emoji:change_me@127.0.0.1:3306/se_emoji?charset=utf8mb4
AUTO_CREATE_TABLES=false
```

4. 安装驱动 `pip install -r backend/requirements-mysql.txt`，初始化数据 `python scripts/seed_demo.py --reset`。
5. 运行接口回归；未通过则回退 SQLite。

如实说明：MySQL 形态只完成 DDL 与连接配置，未在实例上执行全量回归。

## 9 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 启动后 8000 端口占用 | 其他进程占用 | `netstat -ano | findstr :8000`，改端口或结束进程 |
| 页面 404 或空白 | 前端未构建 | 在 `frontend` 执行 `npm run build` 后重启后端 |
| 登录后立即退出 | `SECRET_KEY` 为空且进程重启 | 在 `.env` 配置固定密钥 |
| 中文日志乱码 | 控制台编码 | 启动前 `$env:PYTHONUTF8=1` |
| AI 启动报模型不存在 | 未下载模型 | 执行 `scripts/download_models.py` |
| AI 报无法读取 ONNX | 路径含中文 | 代码已复制到临时目录；仍失败时把模型放到纯英文路径并修改配置 |
| AI 报设备不匹配 | `device_id` 与后端不一致 | 统一 `.env` 与 `config.yaml` |
| AI 上报全部被拒 | 课堂非进行中或时间偏差 | 检查课堂时间与系统时钟；允许过去 60 秒、未来 5 秒 |
| 摄像头打不开 | 设备占用或权限 | 关闭其他占用程序；Windows 设置中允许应用访问摄像头 |
| 学生无法提交 | 不在名单、课堂未开始或时间片内重复 | 查看页面提示；管理员确认名单与时间 |
| 演示课堂全部已结束 | 初始化时间过期 | 执行 `seed_demo.py --refresh` |
| CSV 中文乱码 | 用非 Excel 工具打开 | 文件为 UTF-8 BOM，Excel 直接打开正常 |
| 接口返回 502 或代理错误 | 系统代理拦截 localhost | 设置 `NO_PROXY=127.0.0.1,localhost` 或关闭代理后重试 |
| 看板只轮询、无 WebSocket 推送 | 缺少 `websockets` 或 `wsproto` | `pip install websockets==17.3`；`requirements.txt` 已显式锁定 |

## 10 换机复现检查表

1. 复制仓库，不复制 `.venv`、`node_modules`、`data`。
2. 按 README 创建虚拟环境并安装依赖。
3. 复制 `.env.example`，填写 `SECRET_KEY`、`AI_SERVICE_KEY`。
4. 执行 `seed_demo.py --reset`。
5. 构建前端。
6. 启动后端，打开 `/health` 与 `/docs`。
7. 用三个角色各登录一次。
8. 执行 `seed_demo.py --refresh`，确认有一节进行中课堂。
9. 启动 AI 进程，确认产生一条 AI 记录。
10. 启动桌面客户端，完成一次提交。
11. 记录总用时、失败步骤与解决方式，回填测试报告。
