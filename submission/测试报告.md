# 表情符号课堂情绪检查器系统测试报告

## 1 测试概述

本文用于说明测试范围、测试用例和最终结果，覆盖账号权限、课堂名单、表情提交、历史查询、统计导出、AI 服务、桌面交互和时间处理。

## 2 测试环境与方法

### 2.1 环境与测试数据

| 项目 | 配置或说明 |
| --- | --- |
| 后端运行环境 | Windows 11，Python 3.12.2；FastAPI 0.141.1、Pydantic 2.12.5、SQLAlchemy 2.0.45 |
| 后端自动测试 | pytest、FastAPI TestClient；每个用例使用独立内存 SQLite 与 StaticPool |
| 手工联调存储 | SQLite WAL，项目目录下的 `data/se_emoji.db`，与内存测试库区分 |
| 前端构建环境 | Node.js 22.20.0、npm 10.9.3、Vite 6.4.5 |
| AI 运行环境 | OpenCV 5.0.0、ONNX Runtime 1.20.1、NumPy 2.3.2；回放图片作为集成输入 |
| 前端时间测试环境 | Windows，Node.js 24.22.1，使用 Node 内置测试工具 |

后端测试基座生成管理员、一名授课教师、另一名教师及三名学生，并创建未开始、进行中、已结束和其他教师的课堂。测试使用专用账号、密钥及内存数据库，不改动业务数据库。时间片用例单独启用时间片限制，其余提交用例默认关闭该限制以隔离测试条件。

### 2.2 测试方法

| 方法 | 验证内容 |
| --- | --- |
| 单元测试 | 表情映射、softmax、过滤、上传队列、配置读取、桌面回调和时间格式转换 |
| 接口测试 | 注册登录、密码、用户、排课名单、提交历史、看板统计、导出、AI 入库及角色权限 |
| 接口级端到端 | 管理员创建课程与课堂 → 安排名单 → 学生提交 → 教师查看 → 管理员统计导出 |
| 进程联调 | 回放图片驱动 AI 检测、分类和上传；桌面脚本驱动登录、课堂、历史及提交 |
| 前端构建 | 检查生产构建可完成，确认页面与接口模块可打包 |
| 跨时区测试 | 分别在 UTC、Asia/Shanghai、America/New_York 环境下核对北京时间显示与编辑 |

接口级端到端结果说明 API 之间的业务链路；构建结果说明前端可打包，两者均按各自验证范围记录。

## 5 测试结论

认证权限、课堂名单、手动反馈、历史查询、统计导出和 AI 数据处理在所列接口与单元测试中符合预期，接口级端到端业务链路贯通。AI 回放结果成功匿名入库，桌面核心交互可完成，WebSocket 可发送记录变更信号，前端构建成功。

测试结果表明，系统在已验证范围内满足角色隔离、事件幂等、统计一致性、CSV 安全与异常恢复等要求。
